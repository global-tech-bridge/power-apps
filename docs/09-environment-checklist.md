**先に確認しないと再現できない／再現しても意味がない**項目を優先順に並べたもの。

回答欄はこのファイルに直接書き込んで管理する。

## A. 最優先: 実機で30分で分かる3点

ヤンマー環境にアクセスできる方に、**捨てフローを1つ作って**次を試してもらう。
ヒアリングより実機確認のほうが確実で速い。

| # | 試すこと | 結果 | これが NG なら |
|---:|---|---|---|
| A-1 | Power Automate で「**Microsoft Word テンプレートの入力**」アクションを**追加できるか** | | Premium ライセンス未保有か、DLP でブロック → B と C-1 を確認 |
| A-2 | そのアクションを**実際に実行して成功するか**（適当な Word テンプレートで可） | | **MFA 条件付きアクセスの既知の問題**の可能性 → C-2 |
| A-3 | SharePoint コネクタの「**ファイルの変換**」で `.docx` → PDF が作れるか | | 代替方式も使えないことになる。要調査 |

### A-1 / A-2 が NG の場合に何が起きるか

現在の実装は `Word Online (Business)`（**Premium コネクタ**）でPDFを作っている。
これが使えない場合、**標準コネクタだけでPDFを作る方式に切り替える改修**が必要になる
（HTML を `.doc` として保存し、SharePoint「ファイルの変換」で PDF 化）。
要件定義 10.1 で共有されていた案そのもので、**日本語の文字化けリスクと引き換えに
Premium ライセンスが不要になる**。

判断材料は [07 未確定事項](07-open-issues.md) 19章-13 の表。

### 追加で見てほしいもの

| # | 確認 | 結果 | 理由 |
|---:|---|---|---|
| A-4 | SharePoint のファイルに**秘密度ラベルが自動適用**される設定になっていないか | | 公式リファレンスの既知の問題に「Convert Word Document to PDF は `Confidential` / `Highly Confidential` の秘密度ラベルが付いたファイルを変換できない」とある。自動ラベル付与があると中間ファイルの変換が失敗しうる |

## B. ライセンス（費用と方式が決まる）

### ⚠ ここが最大の費用要因

**Premium コネクタを使うフローをアプリから呼ぶと、そのアプリを使う人**全員**に
Power Apps Premium 相当のライセンスが必要になる。**

Microsoft の記述では、標準コネクタだけのアプリでも、
Premium コネクタを使うフローに接続していればアプリ利用者に Premium 使用権が必要。
アプリの「ライセンス指定」表示が Standard のままでも必要になる点に注意。

つまり現在の実装のままだと、**中部近畿の営業・サービス担当のうちアプリを使う人数 × $20/月**
がかかる。pptx スライド3の「使用は任意とする／トラブルになりそうな案件で活用」という
運用方針に対して、全員分の固定費は割に合わない可能性がある。

### 聞くこと

| # | 質問 | 回答 |
|---:|---|---|
| B-1 | Microsoft 365 のプランは何か（E3 / E5 / Business Premium / Business Standard など） | |
| B-2 | **Power Apps Premium** または **Power Automate Premium** の保有有無。保有している場合、何ライセンスあり、誰に割り当てられているか | |
| B-3 | **Power Apps Pay-As-You-Go**（Azure サブスクリプション課金）は利用可能か。使えるなら「その月にアプリを開いた人だけ課金」になるため、任意運用と相性が良い | |
| B-4 | 新規ライセンス購入の可否と、購入までのリードタイム（申請・承認プロセス） | |
| B-5 | アプリの想定利用者数（中部近畿の営業・サービス担当のうち、実際に使う見込み人数） | |
| B-6 | 試用ライセンス（Power Automate 90日 / Power Apps 30日）の取得がテナント設定で許可されているか | |

### 費用の見積り比較（B-5 の人数で変わる）

| 方式 | 必要ライセンス | 月額の考え方 |
|---|---|---|
| 現在の実装（Word テンプレート） | 利用者全員に Power Apps Premium | 人数 × $20 |
| 現在の実装 ＋ Pay-As-You-Go | Azure 従量課金 | **その月に使った人だけ** × $10 |
| 標準コネクタ方式に改修 | 追加ライセンス不要（M365 付属で可） | $0 |

**B-3 と B-5 の回答で、改修すべきかどうかが決まる。**

## H. 自分のテナントで再現するときの対応表

A〜F の回答が揃ったら、次のように自分のテナント側を合わせる。

| ヤンマー側の条件 | 自分のテナントでの再現方法 |
|---|---|
| Power Apps Premium 保有 | Power Apps Premium の**試用版（30日）**を取得。または Power Automate Premium 試用版（90日） |
| Premium 非保有（標準のみ） | 試用版を**あえて取得しない**。標準コネクタだけで動くかを検証する |
| M365 E3 / E5 | Business Basic では Office デスクトップが無いだけで、SharePoint / Exchange / 標準コネクタは同等。**PDF生成の検証には十分** |
| DLP でコネクタが Business 分類 | 自分のテナントでも同じ分類の DLP ポリシーを作って再現する |
| MFA 条件付きアクセス有効 | **これは再現が難しい。** Entra ID の条件付きアクセスを設定するには Entra ID P1 以上が必要。A-2 の実機確認で代替する |
| 既定環境を使う | 自分のテナントの既定環境を使う（**既定環境は自動作成されるもので、手動作成はできない**） |
| SharePoint 日本語サイト | サイト作成時に言語を日本語にする |
| iPad で運用 | 実機の iPad か、ブラウザを 768×1024 にして検証 |

### 再現しなくてよいもの

| 項目 | 理由 |
|---|---|
| 組織マスタ105件の実データ | [`data/import/OrgMaster.xlsx`](../data/import/OrgMaster.xlsx) をそのまま使えば同じデータで検証できる |
| 実際の顧客情報 | **使ってはいけない**（要件定義15.3）。`テスト太郎` で検証する |
| 利用者数ぶんのライセンス | 検証は1〜2ユーザーで足りる。費用見積りは B-5 の人数で計算する |
